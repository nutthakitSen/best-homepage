Privacy policy

Last updated: November 2026 · DRAFT — review before publishing

This is the personal website of Nutthakit Senphoklang (“Best”). It also serves as the public homepage for a personal OAuth application used to automate my own Google Workspace.

What this site does

This is a static informational site. It does not create accounts, run analytics, set tracking cookies, or collect personal data from visitors.

The OAuth application

A private, personal OAuth client (“nutthakit-space”) accesses my own Google account (Gmail, Calendar, Drive, Docs, Sheets, Contacts) to help me manage my personal workspace. Specifically:

  • Access is limited to the account owner who authorizes it. No other users’ data is accessed.
  • Data is used solely to perform actions I request (read, organize, draft, send).
  • No Google user data is sold, shared with third parties, or used for advertising.
  • OAuth tokens are stored locally on my own machine and are not published by this site.
  • Access can be revoked at any time from my Google Account’s security settings.

Google API Services

This application’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
